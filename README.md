# Clima Local

Previsão do tempo com estados de carregamento e erro.

## Demo

Este projeto é uma demonstração independente de portfólio, com interface responsiva e interações funcionais no navegador.

## Problema

Uma busca de clima com feedbacks claros e uma interface pronta para integrar uma API real.

## Funcionalidades

- Interface responsiva e mobile-first.
- Estados de interação e feedback visual.
- Componentes visuais com hierarquia clara.
- Dados demonstrativos seguros, sem credenciais.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript puro

## Como executar

Abra `index.html` no navegador ou execute:

```bash
python3 -m http.server 8000
```
